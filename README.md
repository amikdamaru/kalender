# Kalender

Aplikasi kalender bulanan sederhana (HTML/CSS/JS, tanpa dependensi) yang bisa diinstal sebagai PWA di Chrome HP.

- Navigasi bulan dengan tombol ‹ › atau geser kiri/kanan
- Catatan per tanggal, tersimpan di `localStorage` perangkat
- Bisa dipakai offline setelah dibuka sekali

Agar bisa diinstal di HP, buka lewat HTTPS (misalnya GitHub Pages). Saat mengubah file, naikkan versi `CACHE` di `sw.js`.
